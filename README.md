# Virtualization overhead: KVM vs. QEMU on IBM Power9 (ppc64le)

Reproducibility repository for the experiment comparing performance
overhead between KVM (hardware-accelerated virtualization) and plain QEMU
(TCG emulation), relative to a bare-metal baseline, on an IBM Power9
(ppc64le) server. The metrics covered are CPU, memory, cache, disk
(fio/ext4), memory bandwidth (STREAM) and GPU (matrixMul/NCCL via CUDA).

## Repository structure

```
environment/     Python dependencies (requirements.txt) and R (r_packages.txt)
src/
  collect/        collection scripts (run on the real Power9 server via Slurm/SSH)
  analysis/       parsing + statistics pipeline (Python) and figure generation (R)
data/
  raw/            raw benchmark logs (.txt), one subdirectory per environment/VM
  processed/      CSVs generated by the analysis pipeline (see docs/REPRODUCE.md)
results/
  figures/        the paper's final figures (PDF) and exploratory plots (PNG)
docs/             methodology, reproduction guide, audit and experiment scenario
```

`data/raw/` uses folder names like `kvm-gabrielly/`, `kvm-lucas/`,
`kvm-ramalho/`, `qemu-lucas/`, etc. — `gabrielly`, `lucas` and `ramalho`.
The author list is in
[CITATION.cff](CITATION.cff).

## Quick start

To reproduce the analysis from the already-collected raw data (already in
`data/raw/`), see the full step-by-step guide in
[docs/REPRODUCE.md](docs/REPRODUCE.md). Summary:

```bash
python -m venv venv && source venv/bin/activate
pip install -r environment/requirements.txt --break-system-packages

python3 src/analysis/analyze_benchmarks.py --logs-dir data/raw --out-dir data/processed
```

## Reproducibility limitation

This work's reproducibility has two levels:

- **Reproducing the ANALYSIS** from the published raw data
  (`data/raw/`) — runs on any machine with Python (no hardware
  requirement). This is the level guaranteed by the artifact kit.
- **Reproducing the original COLLECTION**: the scripts in
  `src/collect/*.sh` require a server with the ppc64le architecture, an
  IBM POWER9 processor, and, for the GPU tests, NVIDIA GPUs with NVLink2
  and VFIO support for passthrough. It doesn't have to be specifically
  the experiment's original server, but any Power9/ppc64le hardware with
  those characteristics allows the collection to be re-run. Exactly
  reproducing the absolute values, however, depends on equivalent
  hardware; this is an external-validity limitation already documented
  in the paper, not a restriction of the artifact kit itself.

See [docs/REPRODUCE.md](docs/REPRODUCE.md) for the full step-by-step
guide for each level.
