# data/processed/

Outputs generated by `python3 src/analysis/analyze_benchmarks.py --logs-dir
data/raw --out-dir data/processed` (see [docs/REPRODUCE.md](../../docs/REPRODUCE.md)).
This file is not overwritten by the pipeline — only the CSVs/JSON below are.

- `extracted_data.csv` — one row per (file, metric), tidy format.
- `descriptive_summary.csv` — mean, median, std dev, IQR per metric x environment.
- `statistical_results.csv` — normality (Shapiro-Wilk), homogeneity
  (Levene), global test (ANOVA/Kruskal-Wallis) with `p_fdr_corrigido`
  (Benjamini-Hochberg across all metrics), Dunn post-hoc, effect
  size, bootstrap CI.
- `vm_heterogeneity.csv` — tests whether the 3 source VMs of each
  treatment (KVM/QEMU) differ from each other per metric (see
  [docs/METHODOLOGICAL_GLOSSARY.md](../../docs/METHODOLOGICAL_GLOSSARY.md)
  for what this means).
- `parsing_warnings.csv` — cases where an expected metric wasn't found
  in some log file (helps explain `n` differences between
  metrics/environments).
- **`duplicate_statistics_alert.csv`** — lists metric pairs whose global
  statistical test produced an exactly identical result. This can be
  benign (equally-sized groups with complete separation between
  environments produce the same Kruskal-Wallis H by mathematical
  construction, regardless of the raw values) or point to a computation
  bug — **review manually before accepting any new case that shows up
  here**. Generated automatically on every pipeline run (not a
  one-off/manual check).
- `metadata.json` — git commit, UTC timestamp and seed of the run that
  generated the files above.
- `report.txt` — human-readable summary of all of this, per metric.
- `plots/`, `heatmaps/`, `confidence_intervals/` — generated in the same
  run; moved to `results/figures/` (see docs/REPRODUCE.md), not kept
  here in the final state.
